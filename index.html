Send It! Racing

A real-time racing platform that connects Assetto Corsa simulators to a live player network — scoring, leaderboards, and token rewards across every venue.

📡

Live telemetry

Reads Assetto Corsa UDP packets directly — speed, gear, throttle, brake, lap times — at 10hz. No plugins, no mods.

🏆

Cross-venue leaderboard

Every lap time is posted to a shared network. Players compete against drivers at every Send It venue simultaneously.

🎯

Token economy

Players earn tokens for every session. Venues push free plays to nearby users to fill idle machines on quiet nights.

Technical stack

Node.js UDP
Listens on port 9996 — catches AC telemetry packets, detects lap completions automatically
WebSocket
Broadcasts live data to venue and player apps in real time — leaderboard updates instantly on lap completion
REST API
Express.js endpoints for session management, leaderboard queries, and venue controls
Venue app
Staff dashboard — live telemetry, session start/end, leaderboard, push token offers to nearby players
Player app
Mobile web — QR check-in, live lap timer, personal bests, cross-venue leaderboard position

This demo runs entirely in the browser with simulated telemetry. The production version connects to a real Assetto Corsa instance on the same local network. View the full source on GitHub.
